# Automated Weather App

This is another n8n project I built while learning automation.

The goal was to automatically get weather information on a schedule and send the result through email. I wanted to practice working with an API and connecting it with other services in n8n.

## How it works

The workflow runs automatically based on a schedule.

It then:

- Gets weather information from OpenWeatherMap
- Processes the weather data
- Sends the result through email

### Workflow

Schedule Trigger → OpenWeatherMap → Send a message → Send a message1

## Tools I used

- n8n
- Schedule Trigger
- OpenWeatherMap API
- Gmail

## Why I made this

I wanted to practice using APIs in n8n and understand how information from an external service can be used in an automated workflow.

This project also helped me understand how scheduled workflows can run without having to manually start them every time.

## What I learned

While working on this project, I learned more about:

- Scheduled triggers
- Working with APIs
- OpenWeatherMap integration
- Passing API data through n8n
- Sending automated emails
- Testing workflows
